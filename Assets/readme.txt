Magnet Hopper is a short puzzle platformer made in Unity.

You play as a small magnet creature escaping a factory. You figure
out you have powers of Magnetism and with that you are able to push
and pull blocks and enemies.

This is a project for 1st year Unity Dev final project.
Tools in Unity used:

Environment
C# Scripts
Animations
Input
User Interface
Audio

The game currently features 1 level.

Controls:

WASD or Arrows
Space Bar - Jump
E - Pull objects
Q - Push objects
